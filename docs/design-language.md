# Vedro / EmbyGo 统一设计语言 (Design Language v2)

适用于 **Vedro 全部客户端**（iOS / Android / macOS / Windows / Android TV，Flutter）与 **EmbyGo Web**（React + Tailwind）。
四套主题共用同一套组件规则，只替换 token。

---

## 0. 三条铁律

1. **能用视觉就不用文字，能用图标就不用文字。**
   - 数量、状态、类型一律用图标 / 色点 / 进度条 / 角标来表达，不写"电影 128 部 · 剧集 36 部 · 1,024 集"这类说明文字。
   - 卡片的说明文字最多两行：**标题** + **一个极短的元信息**（年份，或剧集用 `S1·E3`）。不显示季数、集数、评分、片源数这些文字。
   - 服务器 / 线路卡片只保留：名称、在线状态色点、延迟（带信号图标的数字）、当前选中对勾。媒体统计如果要显示，就用 `🎬 128  📺 36` 这种"图标 + 数字"的小芯片，而且默认折叠。
2. **整页不缩放。** 页面切换和标签切换只做淡入淡出或 ≤10px 的位移，不缩放整页（缩放会让 0.5–1px 的细边框闪烁）。
3. **形状守恒。** 一个元素在动画前后必须是同一个比例、同一个圆角、同一个边框。长按菜单的预览就是卡片封面本身（只包含海报区域，不含标题），从卡片当前位置原样升起。

## 4. 动效（弹簧）

| 名称 | 用途 | Flutter | CSS 时长 + easing |
|---|---|---|---|
| press | 按下 | `VedroSpring.press` | 120ms `--vd-ease-smooth` |
| release | 松手回弹 | `VedroSpring.release` | 420ms `--vd-ease-playful` |
| snappy | 悬停 / 一般交互 | `VedroSpring.snappy` | 320ms `--vd-ease-snappy` |

规则：
- 会回弹的 easing（snappy / bouncy / playful）只能用在 transform（缩放、位移）上，**不能用在 opacity 上**。
- 按下缩放到 0.965（卡片）或 0.92（图标按钮）；桌面悬停放大 1.02。
- 页面切换：淡入 + 上移 10px，420ms smooth，**不缩放**。标签切换：opacity 0.6→1。
- 弹窗：淡入 + 缩放 0.92→1（bouncy）；关闭用 220ms ease-in。
- 遵守系统的"减少动态效果"设置，开启时所有动画瞬间完成。

## 5. 组件

- **海报卡片**：固定比例（2:3 竖版海报 / 16:9 横版），圆角 = card radius，底下两行文字（标题 + 年份）。封面上只允许：已看对勾、继续观看进度条。不显示评分角标、未看集数角标、版本数角标、收藏心形。
- **继续观看卡片**：16:9，带进度条；文字为"标题 / 剩余 32 分钟"；点击即续播，长按 / 右键打开菜单。不在封面正中放播放大圆钮。
- **媒体库卡片**：16:9 封面，库名只出现一次，用图标表示库类型（电影 / 剧集 / 音乐）。
- **服务器卡片**：头像或首字母图标 + 名称 + 状态色点 + 延迟信号图标；选中时右侧显示对勾。不写统计文字。
- **分区标题**：粗体，有"查看全部"时在后面加一个箭头图标，不写"查看全部"四个字。
- **导航**：桌面是居中的玻璃胶囊，选中项用一个会滑动的胶囊块高亮；手机是底部悬浮栏，同样用滑动的选中块。次要功能收进"⋯"菜单。
- **长按 / 右键菜单**：背景模糊 18 + 压暗 48%；预览就是卡片封面，从 1.03 放大到 1.055；菜单是玻璃材质，圆角与预览相同，从预览的边缘弹出。
- **焦点环（电视 / 键盘）**：2px accent 描边加柔和外发光。
